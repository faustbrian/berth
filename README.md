# berth

`berth` standardizes local Laravel environments for faster setup and reliable
daily development.

## Quick Start

1. Install Berth:

```bash
cargo install --git git@github.com:faustbrian/stackctl.git --bin berth --branch main --locked
```

2. Initialize config:

```bash
berth init
```

3. Start services:

```bash
berth start
```
